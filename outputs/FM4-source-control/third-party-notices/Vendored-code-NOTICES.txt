Notices of the small libraries and files that the ReXGlue SDK vendors in its thirdparty folder
(rexglue/rexglue-sdk at commit f5337cdc947ff6d4c4196737e2c807a48f2a1fc2, most of them from Xenia).
Setup copies them into <BuildRoot>\runtime-source\thirdparty; they are not stored in this
repository. Where that copy carries a notice, the block below quotes it verbatim between the
dashed lines; where it carries none, the block names the upstream license. README.txt says
which binary each one ends up in.
